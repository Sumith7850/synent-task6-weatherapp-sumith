# Weather App (API Integration)

## Description
This is a Python-based Weather Application that fetches real-time weather data using an API and displays key information such as temperature, humidity, and weather conditions.

---

## Features
- Fetch real-time weather data
- Supports multiple cities input
- Displays:
  - Temperature (°C)
  - Humidity (%)
  - Weather condition
- Saves data into a CSV file

---

## Technologies Used
- Python
- requests library
- CSV handling
